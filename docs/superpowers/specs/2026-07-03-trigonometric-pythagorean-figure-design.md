# 三角函數文件畢氏恆等式幾何圖補充設計規格

## 1. 目標

在 `docs/Trigonometric-Functions.md` 中加入第三張幾何圖，幫助讀者從幾何角度理解畢氏恆等式

$$
\sin^2 x+\cos^2 x=1.
$$

本次圖的主題是：

- 單位圓上的直角三角形與畢氏恆等式圖

## 2. 插入位置

圖放在 `### 4.2 畢氏恆等式` 段落內，位於公式與幾何說明之間，作為該節的專屬圖示。

這樣安排的原因是：

- 前面的 `2.2` 已經承擔基本定義圖的角色，不適合再塞入更多圖。
- 這張圖直接服務 `4.2` 的內容，能把代數式與幾何圖一一對應。
- 讀者在看到恆等式後，能立刻用直角三角形與單位圓重新理解它。

## 3. 呈現方式

- 使用 `tikz` fenced code block。
- 不新增外部圖片資產。
- 風格對齊目前文件中的前兩張單位圓相關圖與專案內既有 `tikz` 圖。

## 4. 圖中元素

圖內至少包含以下元素：

- 直角座標軸
- 半徑為 1 的單位圓
- 單位圓上的點 `P(\cos x,\sin x)`
- 從原點到 `P` 的半徑線段，標示長度 `1`
- 從 `P` 向 `x` 軸作垂線
- 由原點、投影點與 `P` 構成的直角三角形
- 水平邊標記 `\cos x`
- 垂直邊標記 `\sin x`
- 原點附近的角 `x`

## 5. 配套文字

在圖後補一小段圖說，說明：

- 這是一個斜邊長為 `1` 的直角三角形
- 兩股分別是 `\cos x` 與 `\sin x`
- 因此由畢氏定理可得 `\cos^2 x+\sin^2 x=1`

文字應簡短，作為現有代數證明的幾何補充，而不是重寫整節。
