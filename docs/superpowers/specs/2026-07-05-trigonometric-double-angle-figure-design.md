# 三角函數文件倍角公式幾何圖補充設計規格

## 1. 目標

在 `docs/Trigonometric-Functions.md` 中加入第五張幾何圖，幫助讀者從單位圓與角度翻倍的角度理解倍角公式

$$
\sin 2x=2\sin x\cos x,
$$

$$
\cos 2x=\cos^2 x-\sin^2 x.
$$

本次圖的主題是：

- 單位圓上同時呈現角 `x` 與角 `2x` 的雙點投影圖

## 2. 插入位置

圖放在 `### 4.4 倍角公式` 段落內，位於前兩個主公式

$$
\sin 2x=2\sin x\cos x
$$

與

$$
\cos 2x=\cos^2 x-\sin^2 x
$$

之後、`再配合 \sin^2 x+\cos^2 x=1，可以改寫成兩個等價形式` 這段之前。

這樣安排的原因是：

- 讀者先看到倍角主公式，再立刻看到幾何對應，理解最直接。
- 這張圖主要服務 `x` 與 `2x` 在同一單位圓上的關係，不必等到代數證明才出現。
- 後面的等價形式 `2\cos^2 x-1` 與 `1-2\sin^2 x` 仍保持文字推導，不把圖形責任擴張過頭。

## 3. 呈現方式

- 使用 `tikz` fenced code block。
- 不新增外部圖片資產。
- 風格對齊目前文件中的前四張單位圓相關圖。
- 採用單一座標系與單位圓，不拆成多圖或多面板。
- 採用完整標註版，但避免再加入面積拼接、矩形或差平方構造圖。

## 4. 圖中元素

圖內至少包含以下元素：

- 直角座標軸
- 半徑為 `1` 的單位圓
- 原點 `O`
- 點 `P=(\cos x,\sin x)`，以藍色表示
- 點 `Q=(\cos 2x,\sin 2x)`，以紅色表示
- 從 `O` 指向 `P` 的半徑線段
- 從 `O` 指向 `Q` 的半徑線段
- 從 `P` 向 `x` 軸與 `y` 軸的虛線投影，標出 `\cos x`、`\sin x`
- 從 `Q` 向 `x` 軸與 `y` 軸的虛線投影，標出 `\cos 2x`、`\sin 2x`
- 原點附近較小的角弧標記 `x`
- 原點附近較外層的角弧標記 `2x`
- 半徑長為 `1` 的資訊

圖形應以「角度翻倍後，單位圓點座標也跟著變成 `(\cos 2x,\sin 2x)`」為主軸；不在圖中額外加入面積、矩形或差平方拼接結構。

## 5. 配套文字

在圖後補一小段圖說，說明：

- 點 `Q` 是單位圓上角度為 `2x` 的點，因此它的座標直接給出 `\cos 2x` 與 `\sin 2x`
- 又因為 `2x=x+x`，這張圖可與上一節的和角公式銜接
- 將和角公式中的 `\alpha=\beta=x` 代入，便得到 `\sin 2x=2\sin x\cos x` 與 `\cos 2x=\cos^2 x-\sin^2 x`

文字應簡短，作為倍角公式的幾何補充，而不是重寫整段代數證明。
