# 三角函數文件 Fourier Features 圖設計規格

## 1. 目標

在 `docs/Trigonometric-Functions.md` 的 `### 6.2 Fourier features 與頻率表示` 中加入一張新的 `tikz` 圖，用直觀波形示意說明：

- 低頻成分負責描述整體趨勢；
- 高頻成分負責補上局部細節；
- 把輸入映射到多個不同頻率的正弦餘弦特徵後，模型更容易表示快速變化的訊號。

這張圖的主要任務不是做嚴格的傅立葉分析推導，而是讓讀者快速建立 `Fourier features` 的幾何直觀。

## 2. 插入位置

本次只新增一張圖，放在 `### 6.2 Fourier features 與頻率表示` 中，位於 `\gamma(x)=[\ldots]` 公式之後、這句話之前：

`這種表示稱為 Fourier features。其核心想法是：`

這樣安排的原因是：

- 讀者先看到抽象的多頻率特徵公式；
- 緊接著看到低頻與高頻波形如何組合出更複雜的訊號；
- 下面原本的三個條列就能自然承接圖中的直觀。

## 3. 呈現方式

- 使用單一個 `tikz` fenced code block。
- 不新增外部圖片資產。
- 圖形採用數學直觀版，而不是 AI pipeline 版。
- 用同一個水平輸入軸 `x`，呈現上下三層堆疊的小面板。
- 不另外在 `6.3` 或其他小節重複新增同類型圖。

## 4. 圖面結構

圖形由三個上下堆疊的小面板組成，共用同一個輸入軸概念：

### 4.1 上層：低頻波

- 畫出 `\sin(2\pi x)` 的平滑波形；
- 標註 `low frequency: overall trend`；
- 讓讀者看到低頻成分主要控制大尺度輪廓。

### 4.2 中層：高頻波

- 畫出 `0.35\sin(8\pi x)` 的較快速震盪波形；
- 標註 `high frequency: fine detail`；
- 讓讀者看到高頻成分主要補上細小變化。

### 4.3 下層：合成曲線

- 畫出兩者相加後的曲線

$$
\sin(2\pi x)+0.35\sin(8\pi x)
$$

- 標註 `combined signal`；
- 讓讀者直觀看到高頻如何附著在低頻輪廓上，形成更複雜的訊號。

## 5. 圖內標註內容

圖中應保留簡潔但足夠的標註，至少包含：

- 上層曲線的短標籤 `\sin(2\pi x)`
- 中層曲線的短標籤 `0.35\sin(8\pi x)`
- 下層曲線的短標籤 `combined signal`
- 文字註記 `low frequency: overall trend`
- 文字註記 `high frequency: fine detail`

圖內不需要塞入完整的 `\gamma(x)` 向量公式，也不需要把推導展開成傅立葉級數形式；重點是保留每條曲線自己的簡短標籤，維持讀圖清晰度。

## 6. 配套文字

在圖後補一小段圖說，內容為：

`低頻成分先描述整體輪廓，高頻成分再補上局部細節；把輸入映射到多個不同頻率的正弦餘弦特徵後，模型會更容易表示快速變化的訊號。`

`6.2` 原本的三個條列保留，不重寫整段正文，讓這張圖只作為幾何與波形直觀補充。
