# 三角函數文件方向向量應用圖設計規格

## 1. 目標

在 `docs/Trigonometric-Functions.md` 的 `### 6.6 圖學與機器人中的方向表示` 中加入一張新的 `tikz` 圖，用機器人/載具的平面姿態示意說明：

- 朝向角 `\theta` 不會只作為單獨數值存在；
- 它通常會先轉成方向向量 `(\cos\theta,\sin\theta)`；
- 這個方向向量再被拿來描述前進方向、控制更新或局部座標軸的朝向。

這張圖的主要任務是把 `6.6` 的工程應用條列，收斂成一個具體且直觀的畫面。

## 2. 插入位置

本次只新增一張圖，放在 `### 6.6 圖學與機器人中的方向表示` 中，位於開頭這句話之後：

`在圖學與機器人中，方向通常不是孤立存在，而是與位置、速度、角速度、感測器量測一起出現。`

並放在條列清單之前。

這樣安排的原因是：

- 讀者先看到一個具體的平面姿態場景；
- 再讀後面的四個條列時，會更容易把「朝向角、方向向量、座標轉換」連成同一件事；
- 圖形會特別服務條列中的前兩點，後面條列再擴展到週期運動與學習特徵。

## 3. 呈現方式

- 使用單一個 `tikz` fenced code block。
- 不新增外部圖片資產。
- 採用單一姿態版，而不是轉向前後版或速度版。
- 標註密度採平衡版：保留位置、朝向角與方向向量標籤，不做過度擁擠的控制或導航細節。

## 4. 圖面結構

圖形應在同一組平面座標軸上包含以下元素：

- 平面座標軸
- 機器人或載具的位置點 `p=(x,y)`
- 一個簡單的小車體或三角形輪廓，用來表明這不是抽象幾何點
- 從位置點出發的朝前箭頭，表示朝向方向
- 在位置點附近標出朝向角 `\theta`
- 在方向箭頭旁標註方向向量 `(\cos\theta,\sin\theta)`

圖的重點是讓讀者看到：

- 朝向角 `\theta` 會被轉成平面中的單位方向向量；
- 這個向量才是後續做運動、控制與座標變換時真正可計算的對象；
- 方向表示因此從「角度」變成「向量」。

## 5. 圖內標註內容

圖中至少保留以下標註：

- `p=(x,y)`
- `\theta`
- `(\cos\theta,\sin\theta)`

圖內不需要額外放入速度向量、感測器量測、第二個座標系、旋轉矩陣或控制方程式；只要把位置、朝向角與方向向量之間的關係交代清楚即可。

## 6. 配套文字

在圖後補一小段圖說，內容為：

`在機器人與圖學中，朝向角 \theta 常先轉成方向向量 (\cos\theta,\sin\theta)，再用來描述前進方向、控制更新或局部座標軸的朝向。`

`6.6` 原本的四個條列保留，不重寫正文。這張圖先把前兩點的共同核心直觀化，後面的文字再擴展到週期運動與學習特徵。
