# 三角函數文件設計規格

## 1. 目標

撰寫 `docs/Trigonometric-Functions.md`，提供一份面向大學程度讀者的三角函數講義。文件需同時滿足下列目標：

- 介紹三角函數的基本概念、幾何意義與常見用途。
- 系統整理常用公式，並對核心公式提供偏嚴謹的證明。
- 說明三角函數在 AI 與相關工程領域中的實際應用。
- 維持可查閱性，使文件既可連續閱讀，也可作為速查筆記。

## 2. 讀者與深度

- 讀者：具備大學初等微積分與基礎代數背景的讀者。
- 證明深度：採偏嚴謹寫法，避免只列公式不說明來源。
- 風格：先建立直觀，再給出正式推導；不走純定理集或競賽題解風格。

## 3. 文件結構

文件預定採用下列章節結構：

### 3.1 三角函數的動機與基本定義

- 從直角三角形中的角與邊比出發。
- 引入單位圓定義，說明其比直角三角形定義更一般。
- 說明角度制與弧度制，特別強調弧度在微積分中的自然性。
- 定義 `sin`、`cos`、`tan`、`cot`、`sec`、`csc`。

### 3.2 基本性質

- 定義域與值域。
- 奇偶性。
- 週期性。
- 圖形特徵與對稱性。
- 單位圓上的符號判斷。

### 3.3 常用公式與證明

依主幹到分支的順序組織：

- 倒數關係與商數關係。
- 畢氏恆等式。
- 和差角公式。
- 倍角公式。
- 半角公式。
- 積化和差與和差化積。

其中和差角公式作為主要樞紐，其餘公式盡量由其推出，避免變成彼此獨立的公式表。

### 3.4 反三角函數與微積分關係

- 反三角函數的主值與定義域限制。
- `sin x`、`cos x`、`tan x` 的導數。
- 基本積分公式。
- 用大學程度常見的方法說明上述結果成立的原因。

### 3.5 AI 與工程應用

以機器學習為主，並補充圖學與機器人：

- 週期特徵編碼。
- Fourier features 與頻率表示。
- 位置、時間與季節性訊號建模。
- 為何以 `sin` / `cos` 取代直接使用角度值能減少不連續性問題。
- 2D 旋轉矩陣與座標變換。
- 機器人或圖學中的姿態與方向表示。

### 3.6 小結與速查表

- 統整核心觀念。
- 附常用公式速查表，提升文件的查閱效率。

## 4. 證明策略

### 4.1 定義與幾何基礎

- 直角三角形定義用於建立初步直觀。
- 正式推導優先採用單位圓、座標表示與代數運算。
- 這樣可自然處理任意角、符號變化與週期性。

### 4.2 公式推導路線

- 主幹證明聚焦和差角公式。
- 倍角公式、半角公式、積化和差與和差化積由主幹公式推導。
- 畢氏恆等式從單位圓方程 `x^2 + y^2 = 1` 出發。
- 商數與倒數關係由定義直接推出。

### 4.3 微積分內容

- 導數部分以大學初等分析/微積分常見方法處理。
- 強調弧度制是導數公式簡潔成立的關鍵。
- 不展開過度技術性的嚴格分析細節，但保留邏輯鏈。

## 5. 例子與應用密度

- 每個大節放少量代表性例子，不堆砌大量練習題。
- 例子重點是展示公式如何使用，而非題海演練。
- AI 應用放在正文，不作附錄，因為其屬於本文件的明確目標之一。

預計包含的代表性例子：

- `sin(\alpha+\beta)` 的公式使用。
- 利用倍角或半角公式化簡表達式。
- 用 `(\sin t, \cos t)` 表示週期時間特徵。
- 由旋轉後座標推導 2D 旋轉矩陣。

## 6. 寫作與排版要求

- 使用繁體中文。
- 公式以 LaTeX 區塊與行內數學表示。
- 標題層級清楚，適合 Markdown 閱讀。
- 文字風格偏講義式，兼顧敘述與可查閱性。

## 7. 非目標

下列內容不納入本次文件主體：

- 冷門或高度技巧性的三角恆等變形大全。
- 大量練習題與習題詳解。
- 超出大學基礎範圍的複分析或調和分析延伸。
- 3D 旋轉的完整李群/四元數體系，只做必要點到為止。

## 9. 驗收標準

當 `docs/Trigonometric-Functions.md` 完成時，應滿足以下條件：

- 能獨立說明三角函數的核心概念與幾何意義。
- 包含常用公式，且核心公式有可追蹤的推導或證明。
- 對大學程度讀者而言，內容完整但不失可讀性。
- 清楚交代 AI 與工程上的主要應用，尤其是機器學習中的週期特徵表示。
- 文件末尾具備可快速查找的公式整理。
