# 三角函數文件 2D 旋轉矩陣圖設計規格

## 1. 目標

在 `docs/Trigonometric-Functions.md` 的 `### 6.5 2D 旋轉矩陣與座標變換` 中加入一張新的 `tikz` 圖，用一般點的幾何旋轉說明：

- 向量 `\begin{pmatrix}x\\y\end{pmatrix}` 經過逆時針旋轉 `\theta` 後，會變成新的向量 `\begin{pmatrix}x'\\y'\end{pmatrix}`；
- 旋轉前後向量長度不變；
- 座標改變的原因是向量在座標軸上的投影改變了。

這張圖的主要任務是幫助讀者把旋轉矩陣公式和實際幾何動作對起來，而不是把整個矩陣乘法過程重新畫進圖裡。

## 2. 插入位置

本次只新增一張圖，放在 `### 6.5 2D 旋轉矩陣與座標變換` 中，位於第一個旋轉矩陣公式

$$
\begin{pmatrix}
x'\\
y'
\end{pmatrix}
=
\begin{pmatrix}
\cos\theta & -\sin\theta\\
\sin\theta & \cos\theta
\end{pmatrix}
\begin{pmatrix}
x\\
y
\end{pmatrix}
$$

之後、`也就是` 這句之前。

這樣安排的原因是：

- 讀者先看到代數形式；
- 緊接著看到幾何上「點被旋轉」的直觀；
- 後面既有的分量式與 `例 4：旋轉 (1,0)` 可以自然承接，不需要重寫正文。

## 3. 呈現方式

- 使用單一個 `tikz` fenced code block。
- 不新增外部圖片資產。
- 採用一般點旋轉版，而不是單位圓特例版。
- 標註密度採平衡版：保留點、向量、角度與少量座標投影，不做過度擁擠的矩陣內嵌說明。

## 4. 圖面結構

圖形應在同一組座標軸上包含以下元素：

- 原點 `O`
- 原向量 `OP`
- 旋轉後向量 `OP'`
- 點 `P(x,y)`
- 點 `P'(x',y')`
- 在 `O` 附近標出逆時針旋轉角 `\theta`
- 一個小型旋轉箭頭，顯示從 `OP` 轉到 `OP'`
- 從 `P` 向座標軸作虛線投影，標示 `x` 與 `y`
- 從 `P'` 向座標軸作虛線投影，標示 `x'` 與 `y'`

圖的重點是讓讀者看到：

- 同一個點經過旋轉後，方向改變；
- 長度維持不變；
- 座標值則因投影改變而變成新的 `x'` 與 `y'`。

## 5. 圖內標註內容

圖中至少保留以下標註：

- `P(x,y)`
- `P'(x',y')`
- `x`
- `y`
- `x'`
- `y'`
- `\theta`

圖內不需要再塞入完整矩陣乘法展開，也不需要額外標註向量長度公式；只要讓幾何關係清楚、可直接回對到正文中的

$$
x'=x\cos\theta-y\sin\theta,\qquad
y'=x\sin\theta+y\cos\theta
$$

即可。

## 6. 配套文字

在圖後補一小段圖說，內容為：

`旋轉矩陣可以看成把向量整體逆時針轉過 \theta；同一個點在旋轉前後長度不變，但它在座標軸上的投影會改變，因此得到新的座標 $(x',y')$。`

`6.5` 原有後半段的分量式說明與 `例 4：旋轉 (1,0)` 保留，不重寫正文。這張圖先服務一般點的幾何直觀，後面的文字再接回基底向量與單位圓的觀點。
