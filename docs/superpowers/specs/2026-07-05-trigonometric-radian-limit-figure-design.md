# 三角函數文件基本極限與弧度制幾何圖補充設計規格

## 1. 目標

在 `docs/Trigonometric-Functions.md` 中加入第六張幾何圖，幫助讀者同時理解弧度制的自然性與基本極限

$$
\lim_{h\to 0}\frac{\sin h}{h}=1.
$$

本次圖的主題是：

- 以單位圓上下雙面板同時呈現「弧度 = 弧長」與 `\sin h < h < \tan h` 的幾何夾擠圖

## 2. 插入位置

圖放在 `### 5.2 兩個基本極限與弧度制` 段落內，位於兩個極限公式

$$
\lim_{h\to 0}\frac{\sin h}{h}=1
$$

與

$$
\lim_{h\to 0}\frac{\cos h-1}{h}=0
$$

之後、`第一個極限若用幾何夾擠可以證明` 這段之前。

這樣安排的原因是：

- 讀者先看到本節核心極限，再立刻知道這張圖是為哪個問題服務。
- 上半板可先建立弧度制的幾何直觀，下半板再接到第一個極限的夾擠思路。
- 第二個極限 `(\cos h-1)/h` 的推導仍維持文字證明，不把單張圖的責任擴張過頭。

## 3. 呈現方式

- 使用單一個 `tikz` fenced code block。
- 圖內採上下雙面板配置。
- 不新增外部圖片資產。
- 風格對齊目前文件中的前五張單位圓相關圖。
- 採用幾何圖形加少量不等式小標註，不塞入完整極限證明文字。

## 4. 圖中元素

圖內至少包含以下元素：

### 上半板：弧度制直觀

- 單位圓
- 原點 `O`
- 一個小角 `h`
- 與該角對應的圓弧，標記為 `h`
- 角標記也寫 `h`
- 小型文字標註「半徑 `1` 時，弧長 = `h`」

### 下半板：幾何夾擠

- 同樣以單位圓與小角 `h` 為背景
- 原點到圓上點的半徑線段
- 對應內側垂直邊，標記 `\sin h`
- 對應圓弧，標記 `h`
- 外側切線段，標記 `\tan h`
- 小型不等式標註 `\sin h < h < \tan h`
- 若版面允許，可再補一行較小的推進式 `1 < h/\sin h < 1/\cos h`

圖形應保持在同一個單位圓與小角 `h` 的語境內，不再額外引入第二個極限的專屬構造。

## 5. 配套文字

在圖後補一小段圖說，說明：

- 上半板表示在單位圓中，若角度用弧度表示，角 `h` 對應的弧長就是 `h` 本身
- 這說明弧度制對極限與微積分特別自然
- 下半板則用幾何關係呈現 `\sin h < h < \tan h`
- 進一步可推出 `1 < h/\sin h < 1/\cos h`，在 `h\to 0` 時夾出 `\sin h/h \to 1`

文字應簡短，作為 `5.2` 的幾何補充，而不是重寫整段極限證明。
