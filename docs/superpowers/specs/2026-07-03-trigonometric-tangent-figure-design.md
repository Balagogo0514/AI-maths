# 三角函數文件正切幾何圖補充設計規格

## 1. 目標

在 `docs/Trigonometric-Functions.md` 中加入第二張幾何圖，幫助讀者理解 `\tan\theta` 的幾何意義。

本次圖的主題是：

- 單位圓右端點切線上的 `\tan\theta` 幾何圖

## 2. 插入位置

圖放在 `### 2.2 單位圓中的定義` 段落內，接在現有單位圓 `\sin/\cos` 圖與其圖說之後，並放在「這一定義比直角三角形更根本」的說明之前。

這樣的順序為：

1. 先理解 `\cos\theta` 與 `\sin\theta` 是單位圓上的座標
2. 再理解 `\tan\theta` 是從同一個角延伸出的切線高度
3. 最後回到單位圓定義較一般的結論

## 3. 呈現方式

- 使用 `tikz` fenced code block。
- 不新增外部圖片資產。
- 風格對齊目前文件中已存在的單位圓圖，以及專案內既有 `tikz` 圖。

## 4. 圖中元素

圖內至少包含以下元素：

- 直角座標軸
- 半徑為 1 的單位圓
- 單位圓右端點 `(1,0)`
- 在 `(1,0)` 的垂直切線 `x=1`
- 從原點出發、與正 `x` 軸夾角為 `\theta` 的射線
- 射線與切線的交點 `T`
- 角度 `\theta` 的圓弧標記
- 從 `(1,0)` 到 `T` 的線段標記 `\tan\theta`

## 5. 配套文字

在圖後補一小段圖說，說明：

- 射線的斜率是 `\tan\theta`
- 射線可寫成 `y=(\tan\theta)x`
- 在切線 `x=1` 上，高度就變成 `y=\tan\theta`

這段說明應簡潔，目的是把圖與代數定義直接連起來。
