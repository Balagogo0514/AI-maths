# 三角函數文件幾何圖補充設計規格

## 1. 目標

在 `docs/Trigonometric-Functions.md` 中加入一張幾何圖，幫助讀者理解單位圓定義下的三角函數意義。

本次只處理一張圖：

- 單位圓與點 $P(\cos\theta,\sin\theta)$ 的幾何意義圖

## 2. 插入位置

圖放在 `### 2.2 單位圓中的定義` 段落中，介於六個三角函數定義與「這一定義比直角三角形更根本」的說明之間。

這樣安排的原因是：

- 讀者剛看完 `\cos\theta=x`、`\sin\theta=y` 的定義，立刻看到幾何圖最自然。
- 圖能直接支撐後文對座標、正負號、週期性與旋轉的說明。

## 3. 呈現方式

- 使用現有專案已經採用的 `tikz` fenced code block。
- 不新增外部圖片檔。
- 寫法對齊 `docs/Euler-Identity.md` 與 `docs/Matrix.md` 中的圖形風格。

## 4. 圖中元素

圖內至少包含以下元素：

- 直角座標軸
- 半徑為 1 的單位圓
- 原點 `O`
- 第一象限中的點 `P`
- 從原點到 `P` 的半徑線段
- 從 `P` 向 `x` 軸、`y` 軸作虛線投影
- 角度 `\theta` 的圓弧標記
- 點 `P` 的標記 `(\cos\theta,\sin\theta)`
- 對 `x`、`y` 軸投影的文字標記，對應 `\cos\theta` 與 `\sin\theta`

## 5. 配套文字

在圖後補一小段圖說，明確說出：

- 水平座標對應 `\cos\theta`
- 垂直座標對應 `\sin\theta`
- 因此三角函數可以被理解為單位圓上的座標函數

圖說應簡短，不與正文重複大段解釋。
