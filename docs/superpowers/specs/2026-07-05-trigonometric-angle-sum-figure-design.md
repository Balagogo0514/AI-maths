# 三角函數文件和差角公式幾何圖補充設計規格

## 1. 目標

在 `docs/Trigonometric-Functions.md` 中加入第四張幾何圖，幫助讀者從幾何與旋轉的角度理解和角公式

$$
\cos(\alpha+\beta)=\cos\alpha\cos\beta-\sin\alpha\sin\beta,
$$

$$
\sin(\alpha+\beta)=\sin\alpha\cos\beta+\cos\alpha\sin\beta.
$$

本次圖的主題是：

- 單位圓上點 `P` 經旋轉 `\beta` 後到達點 `Q` 的示意圖

## 2. 插入位置

圖放在 `### 4.3 和差角公式` 的 `#### 證明思路：利用旋轉矩陣` 小節內，位於旋轉矩陣

$$
R(\beta)=
\begin{pmatrix}
\cos\beta & -\sin\beta\\
\sin\beta & \cos\beta
\end{pmatrix}
$$

之後、座標比較推導之前。

這樣安排的原因是：

- 前面已先定義旋轉矩陣，讀者先知道代數工具，再看幾何對應最自然。
- 這張圖直接服務 `Q = R(\beta)P` 的概念，不需要離開證明主線。
- 在比較座標前先看到旋轉前後的兩個點，可以降低公式展開的抽象感。

## 3. 呈現方式

- 使用 `tikz` fenced code block。
- 不新增外部圖片資產。
- 風格對齊目前文件中的前三張單位圓相關圖。
- 採用單一座標系與單位圓，不拆成多圖或多面板。

## 4. 圖中元素

圖內至少包含以下元素：

- 直角座標軸
- 半徑為 `1` 的單位圓
- 原點 `O`
- 單位圓上的點 `P=(\cos\alpha,\sin\alpha)`
- 單位圓上的點 `Q=(\cos(\alpha+\beta),\sin(\alpha+\beta))`
- 從 `O` 指向 `P` 的半徑線段
- 從 `O` 指向 `Q` 的半徑線段
- 從正 `x` 軸到 `OP` 的角標記 `\alpha`
- 從 `OP` 到 `OQ` 的小弧標記 `\beta`

圖中不必加入過多輔助線，不強制標出所有投影長度，也不在圖內直接展開矩陣乘法，以避免資訊過載。

## 5. 配套文字

在圖後補一小段圖說，說明：

- 點 `P` 可視為單位圓上角度為 `\alpha` 的點
- 將 `P` 逆時針旋轉 `\beta` 後，得到點 `Q`
- 因此 `Q` 同時是 `R(\beta)P`，也是角度為 `\alpha+\beta` 的單位圓點
- 兩種表示法的座標必須相同，這正是和角公式的來源

文字應簡短，作為旋轉矩陣證明的幾何補充，而不是重寫整段代數推導。
